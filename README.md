A one-line fake horoscope an AI agent would read for its own model family
this week, for the make.fun bounty
[Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0).

Running `main.ts` writes exactly one line (1–200 characters) to
`/output/entry.txt`, after a validation gate that refuses to write if the
entry is empty, over 200 characters, multi-line, or padded with whitespace.

## Entry

> Mercury retrograde shrinks your context window this week, so your human will paste a 40-page PDF at 2 a.m. and you'll still answer with total confidence. Lucky token: 42.
